# CSV整形（GAS版）の使い方

ブラウザ版と同じ整形を、Google スプレッドシートの中で行うスクリプトです。元のシートは書き換えず、「整形結果」シートに出力します。外部への送信はしません。

## 準備（最初の1回だけ）
1. Google スプレッドシートを新しく作る
2. メニューの「ファイル」→「インポート」→「アップロード」で CSV を取り込む（お試しは `../sample/` の架空データ）
   - 「インポート場所」は「新しいシートを挿入する」、「区切り文字の種類」は「カンマ」
   - 「テキストを数値、日付、数式に変換する」は**外す**（先頭の0や「Ｍ００１」などを元のまま取り込むため）
3. メニューの「拡張機能」→「Apps Script」を開く
4. 最初からある `コード.gs` の中身を消し、`CSV整形.gs` の中身を貼り付けて保存する
5. スプレッドシートの画面に戻って再読み込みすると、メニューに「CSV整形」が出る

## 使い方
1. 整形したいデータのシートを開く（1行目が見出し、2行目以降がデータ）
2. メニューの「CSV整形」→「いまのシートを整形する」
3. 初回だけ「承認が必要です」と表示されるので、自分のアカウントで許可する（このスプレッドシートの読み書きだけに使う）
4. 「整形結果」シートができ、読み込んだ行数・削除した重複・書き換えたセル数が表示される
5. CSVで保存したいときは「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」

## 設定の変え方（`CSV整形.gs` の先頭の CONFIG）
| 項目 | 内容 | 例 |
|---|---|---|
| `columns` | 出力する列と並び順（見出し名）。`[]` なら全列 | `['会員番号', '氏名', '入会日']` |
| `halfwidth` | 英数字・記号を半角に | `true` |
| `fullKana` | 半角カナを全角に | `true` |
| `trim` | 前後の空白と連続した空白を整理 | `true` |
| `dateColumns` | 日付としてそろえる列。`[]` なら自動判定 | `['入会日']` |
| `dateFormat` | 日付の形式 | `'yyyy/MM/dd'` / `'yyyy-MM-dd'` / `'yyyy年M月d日'` |
| `dedupe` | 重複削除のしかた | `'none'` / `'row'` / `'keys'` |
| `dedupeKeys` | `'keys'` のときに比べる列 | `['会員番号']` |
| `keepAsText` | すべて文字列として書き込む（先頭の0や電話番号が変わらない） | `true` |

## 注意
- Google のスクリプトとして動くため、Google アカウントでの承認が必要です
- 大量のデータ（数万行以上）は処理に時間がかかることがあります
- 動作確認: 処理の部分は Node.js でスプレッドシートの動きをまねたテストで確認済み。実際の Google スプレッドシート上での実行は未確認（要確認）
