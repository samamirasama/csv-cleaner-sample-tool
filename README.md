# CSV整形ツール（ポートフォリオ用サンプル）

> **このツールはポートフォリオ用の架空のサンプルです。** 同梱のサンプルデータ（名前・会社・店舗・連絡先）はすべて架空で、実在の人物・会社とは関係ありません。メールアドレスは例示用のドメイン（example.jp）、電話番号は 000 から始まる存在しない番号です。

## 何ができるか
売上表や名簿の CSV を読み込み、よくある「表記ゆれ」をまとめて直して、Excel で開ける CSV としてダウンロードできます。

| 機能 | 内容 |
|---|---|
| 列の並べ替え・選択 | 出力する列を選び、↑↓ボタンで順番を入れ替える |
| 全角・半角の統一 | 英数字・記号を半角に（ＡＢ－１０１ → AB-101）、半角カナを全角に（ﾌﾞﾚﾝﾄﾞ → ブレンド）、余分な空白を整理 |
| 日付形式の統一 | 2026/1/5・2026-01-05・2026年1月5日・令和8年1月5日・R8.1.5・20260105 を読み取り、1つの形式にそろえる。日付の列は自動で判定。読み取れない値は一覧で知らせる |
| 重複削除 | すべての列が同じ行、または選んだ列（会員番号など）が同じ行を削除。整形したあとの値で比べる |
| 読み込み | UTF-8 と Shift_JIS（Excel で保存した CSV）を自動で判別 |
| ダウンロード | UTF-8（BOM付き）・改行 CRLF の CSV。Excel 2010 でも文字化けせずに開ける |

- サーバー不要。HTML / CSS / JavaScript だけで動き、**データはパソコンの外に送信しません**（外部ライブラリ・外部の読み込みもなし）
- 同じ整形を Google スプレッドシートで行う **GAS 版**（`gas/`）付き

## 使い方（ブラウザ版）
1. `index.html` をブラウザ（Chrome / Edge）で開く
2. CSV をドラッグするか、クリックして選ぶ（お試しは「売上表のサンプル」「名簿のサンプル」ボタン）
3. STEP 2 で整え方を選ぶ（変えるとすぐ結果に反映）
4. STEP 3 で結果を確認し、「CSVをダウンロード」

## 使い方（GAS版）
`gas/使い方.md` を参照してください。

## ファイル構成
```
04_業務ツール_CSV整形/
├─ index.html          画面
├─ css/style.css       見た目（スマホ対応）
├─ js/csv-core.js      CSVの読み書きと整形処理（画面に依存しない部分）
├─ js/main.js          画面の操作
├─ js/sample-data.js   お試しボタン用のサンプルデータ（sample/ と同じ内容）
├─ sample/
│  ├─ sample_売上表.csv  架空の売上データ（表記ゆれ・重複入り）
│  └─ sample_名簿.csv    架空の会員名簿（表記ゆれ・重複入り）
└─ gas/
   ├─ CSV整形.gs        Google Apps Script 版
   └─ 使い方.md
```

## 公開（GitHub Pages）
フォルダの中身をそのままリポジトリの直下に置き、Settings → Pages で「main ブランチ / root」を選ぶと公開できます。ビルドは不要です。

## 提案文での紹介例
> Excel・スプレッドシートの小さな業務ツールのサンプルとして、CSV の表記ゆれ（全角半角・日付形式）と重複をまとめて直すツールを作りました（架空のデータで動かせます）。ブラウザ版と GAS 版があります。
